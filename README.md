# Meridian Execution Engine

Trading execution service for the Meridian desk.  The `main` branch carries
the current production revision; `release-2.0` carries the refactor that is
being prepared for rollout.

Operational documents:

* `audit/findings_register.json` -- compliance findings tracked against the
  production revision of the engine.
* `docs/audit_policy.md` -- how findings are tracked and escalated.
